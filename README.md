# DocuVerify

Intelligent Document Authenticity & Forgery Detection — an evidence-based document-forensics platform.

Multi-signal pipeline: OCR/native text extraction → layout, typography, visual, metadata, semantic and text-layer analyzers → anomaly aggregation → explainable assessment with suspicious-region highlights.

## Setup

Backend (Python 3.13):

```
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Frontend (Node 22):

```
cd frontend
npm install
```

Auth service (Node 22, Better Auth + Hono + SQLite):

```
cd auth
npm install
```

> Note: this environment reaches pypi.org slowly — the venv pip config already points at the Aliyun mirror.

## Run

Terminal 1 — backend (serves the built frontend too):

```
cd backend
.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
```

Terminal 2 — auth service (Better Auth, seeds the sample user on first start):

```
cd auth
npm run dev
```

Terminal 3 — frontend dev server (hot reload + `/api` proxy):

```
cd frontend
npm run dev
```

Then open `http://localhost:5173` and sign in with the sample account:

```
email:    test@docu.com
password: password
```

The app is gated behind Better Auth email/password login (session cookie shared with the auth service). The Vite dev server proxies `/api/auth` → the auth service (port 4000); FastAPI proxies it too, so the single-server production build also works. For a production-like single server, use `npm run build` in `frontend` then just the backend on `http://localhost:8000`.

## Test / dataset

Synthetic corpora (no real personal data) in `backend/sample_data/`. All sample documents are generated by scripts, never real paperwork.

Certificate corpus:

- `genuine_cert.pdf` — unmodified
- `forged_*.pdf` — each with one known edit (name, CGPA, date, font, layout shift, metadata, pasted logo)
- `forged_demo.pdf` — combined edits for the before/after demo

IRS Form W-2 corpus (built from the official blank form `fw2_source.pdf`, filled in programmatically):

- `genuine_w2.pdf` — the official form filled once with consistent values (the "real" document)
- `forged_w2_wages.pdf` — inflated wages/withholding re-rendered in foreign fonts, misaligned
- `forged_w2_ssn.pdf` — a pasted low-resolution sticker replaces the printed SSN
- `forged_w2_metadata.pdf` — producer rewritten to "Adobe Photoshop CS6", odd timestamps
- `forged_demo_w2.pdf` — combined W-2 edits for the before/after demo

Regenerate/extend: certificate `backend/spike/forge_cert.py`, W-2 `backend/spike/forge_w2.py`. Run validation:

```
cd backend
.venv\Scripts\python.exe -m pytest tests -q
```

Reference results (computed from actual runs; `spike/evaluate.py` for certificates, `spike/eval_w2.py` for W-2):

| document       | risk  | score |
|----------------|-------|-------|
| genuine_cert   | LOW   | 0.0   |
| forged_demo    | MEDIUM| ~40   |
| genuine_w2     | LOW   | 1.0   |
| forged_demo_w2 | HIGH  | ~77   |

## API

- `POST /api/auth/*` — Better Auth endpoints (sign-in/out, session) proxied to the auth service
- `POST /api/documents` — multipart upload (PDF/JPG/PNG, ≤25 MB, magic-byte validated)
- `GET /api/jobs/{id}` — status + full forensic report
- `GET /api/jobs/{id}/pages/page_{n}.png` — normalized page render used for overlays

## Honesty notes

- Suspicion score is an evidence-based indicator, **not** a calibrated probability of forgery.
- Signals are heuristic; the report always includes the disclaimer: *forensic indicators are algorithmic signals, not legal proof of forgery.*

## LLM layer (optional)

When `backend/.env` has `LLM_ENABLED=true` + a valid key, the pipeline adds a semantic-reasoning pass on top of the deterministic analyzers (an OpenAI-compatible chat call), producing:

- additional semantic-inconsistency findings (`semantic_llm` module) with highlighted regions
- a natural-language executive summary

Free OpenRouter model currently in use: `minimax/minimax-m3:free` (swap `LLM_MODEL` is one line). If a free model is rate-limited, the pipeline falls back gracefully — the deterministic analyzers always deliver the full report.
